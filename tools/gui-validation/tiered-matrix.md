# 全版本 GUI 验证分层

范围：`dev` 上 1.21.1～26.2，15 个游戏版本 × Fabric / NeoForge = 30 个目标。
这是 GUI 验证矩阵；每个目标的 Gradle 构建和 JVM 测试仍全部执行，不能代替 GUI。

| 版本 | 等级 | 仓库中的主要依据 |
| --- | --- | --- |
| 1.21.1 | 全量 | 支持下限，旧槽位回调；复用第二轮 `81bb884` 的 26 通过/2 阻塞证据 |
| 1.21.2 | 全量 | 槽位插入 API 和 `legacy_pair_render` 首版、配方资源切换 |

首次建立矩阵以覆盖所有实际兼容层为先，因此全量版本多于仅按发布名气选点。
后续提交按改动影响缩减：不变版本可引用已验证代码基准；修改共享会话/菜单需重跑各兼容层，
修改某个版本层需重跑该层所有目标。快速组一旦失败，修复后提升相关场景至全量并保留失败证据。

外部核对：[Fabric 1.21.9/1.21.10 迁移说明](https://fabricmc.net/2025/09/23/1219.html)
确认了输入与渲染分界；[Java 26.2 发布说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-2)
列出图形与数据包变化。[Java 26.3](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3)
已于 2026-09-15 发布，本轮不新增该目标；仓库也没有 26.2.1 目标。

## 全量验证 F

以 [28 项用例](cases-1.21.1.md) 为业务清单，两个加载器分别执行：

- 转换台 C01～C12：布局/限制、费用边界、两种付款、搜索分页、连续领取、模板合法性、
  自动复制补位、菜单重开、世界重进、菜单打开时 reload。
- 附魔台 E01～E10：连续取书、输入槽/空生成槽/同名生成槽插书、三轮拆分放回、
  全附魔导出、无效物品拒绝、合并与导出结果持久化。
- 配置 K01～K06：同级递增、不同级/混合书原子拒绝、等级上限、新附魔超上限例外、
  免费一级兑换、免费复制保留模板等级。退出客户端后切换配置，结束恢复原文件。

另加两个版本适配检查，形成 30 个检查项：

- V01：实际世界内观察两种台子的模型、材质和悬浮书，打开 GUI 检查图标、分页按钮和物品提示。
  不能仅凭菜单可打开断言方块实体渲染正常。
- V02：搜索框输入包含 `e` 的英文关键字、Backspace 清空、Esc 关闭后重开；
  `e` 应输入文本而不是触发背包关闭。按新旧键盘事件分支确认输入、焦点和按钮行为。

“全量”指本项目约定的回归清单，并非穷尽所有玩法。E02/E06 的 Shift+鼠标在当前工具下仍
记 BLOCKED；其余通过不能替代。原第二轮 1.21.1 的业务结果单独标为复用，新 V 项需补验。

## 快速验证 Q

快速组保留高风险路径，取消边界组合与配置重启；检查合并为 8 个场景，不冒充 28 项全量：

| ID | 操作与通过条件 | 关联全量项 |
| --- | --- | --- |
| Q01 | 启动进入专用世界，两种台子模型、材质、界面和提示正常 | C01、V01 |
| Q02 | 2 书/36 绿宝石普通兑换，剩 1 书；保存重进后费用和玩家结果均保持 | C04、C10、C11 普通 |
| Q03 | 3 书/12 块和 V 级模板生成、领取、补位；保存重进后 1 书/4 块和模板/输出全保持 | C08、C10、C11 复制 |
| Q04 | 搜索、无匹配、清空、分页及 reload 后领取；输入焦点正确 | C06、C07、C12、V02 |
| Q05 | 连续普通取四个附魔，无幽灵槽；重新准备后导出四附魔整书 | E01、E08 |
| Q06 | 输入槽、空生成槽、同名槽插书，书被消耗；最终等级正确 | E03、E04、E05 |
| Q07 | Looting III 普通拆出 I 再放回，连续三轮 III→II→III | E07 |
| Q08 | 保存重进核对合并后工具/导出书，物品数和附魔组件一致 | E10 |

Q02/Q03/Q07 必须每个目标实际执行：首轮三个缺陷均在这些路径，不能仅依据相邻版本推断。
配置组不执行要明确为 NOT_SCHEDULED，不填写 PASS；Shift 路径也不会混入普通取书计数。

## 操作与证据约定

使用独立命名的测试世界，不改日常存档；数据包只准备前置和读取原版服务端数据。
各目标独立保存代码基准、加载器版本、配置、日志和关键截图。PASS 必须同时符合 GUI 和
服务端物品结果；构建失败、游戏启动失败、工具阻塞、已知加载器问题分开记录。

每次搜索或切换界面后读取实际状态再点击，不使用固定延迟代替确认；跨版本坐标需重新核对。
数据包 pack 版本从对应 Minecraft JAR 的 `version.json` 读取，1.21.5+ 附魔组件命令适配新格式。
不会把命令准备材料或直接修改 NBT 算作 GUI 业务操作。

NeoForge 1.21.9 的 Mods 列表崩溃已有[接受记录](../../.ai/maintenance/known-issues-2026-07-19.md)，
本轮配置使用文件切换，不添加绕过加载器内部逻辑的补丁。
多人、漏斗、满背包、QUICK_CRAFT、快速搜索点击竞态、全部配置组合和性能压力不在本轮范围。
