## 修复

- R1-01：普通兑换直接缩减库存内 `ItemStack`，未调用持久库存写入回调，导致已保存的区块
  可能不再标脏。现在先复制两份材料栈，扣费后写回各槽，通知库存保存。免费模式不写材料槽。
- R1-02：客户端接收模板槽时，复制输出槽可能尚未同步，库存回调误以为可生成一次结果并扣掉
  客户端材料。NeoForge 与 Fabric 1.21.1 的方块实体现在只允许服务端刷新复制结果；
  Fabric 普通兑换领取也只由服务端扣费。
- R1-03：Fabric 的空槽 `setByPlayer` 和 `onTake` 都会扣除源书等级。
  原版 `Slot.tryRemove` 清空槽位后，`safeTake` 随后调用 `onTake`，单击因此触发两次扣除。
  现在空槽回调只清槽，源书扣除统一留给 `onTake`；保留已有插书与交换处理。

R1-02 的 Fabric 版本层改动限于 `legacy`（1.21.1）；其他 Fabric 版本的对应层不在本轮 GUI 修复范围。
共享会话及共享菜单改动会被其他版本使用，因此另外做代表版本构建检查，但不据此声称它们经过 GUI 验收。
