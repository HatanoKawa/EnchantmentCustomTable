# AI Notes

This directory stores AI-produced project notes that are useful beyond a single chat turn.

## Structure

- `backlog/`: review findings, maintenance todo lists, and unresolved follow-up items.
- `design/`: intended product behavior and functional specifications.
- `maintenance/`: repair progress reports and operational follow-up notes.
- `migration/`: version migration plans, compatibility notes, and source version data.
- `testing/`: test strategy, test refactor plans, and verification notes.

Keep documents concise and prefer updating an existing topic file over adding another root-level note.
